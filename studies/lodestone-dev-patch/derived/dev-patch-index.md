# Dev / patch index

> Use the stable source-object citations below to locate this study's evidence.

ordered by date. Prose transcriptions of official Square Enix posts - patch
history and design intent for FFXIV 1.x. Per-page provenance (topic URL) is
in `file-inventory.csv`. Evidence tier: first-party dev communication of
*intent*; observed packet/video still outranks it for runtime values.
