# SE forum Second Wind claims

## Study contents

This study preserves the Second Wind input and calculation claims from post 4
of "2nd wind modifier." It contains one selected source excerpt, one normalized
claim ledger, and a tiered comparison with existing packet, video, and web
records.

The source is a player calculation hosted on the official FFXIV forum. It is
wiki tier and CALIBRATION grade. Hosting does not make the claims official
Square Enix mechanics documentation.

## Promoted conclusions

The claim ledger is suitable as a stable public provenance record. Existing
retail packet rows confirm self-targeted HP recovery values for command 27100,
but they do not expose the level, INT, trait, gear, buff, or random inputs needed
to test the claimed calculation. No formula or server policy is promoted.

## Topics

- Class level as a claimed primary input
- Pugilist INT return
- Enhanced Second Wind's claimed 25 percent increase
- A claimed random integer term
- Level 50 worked examples
- Packet and video observation limits

## Evidence gaps

- The post has no patch marker or raw trial log.
- One level 50 anchor cannot establish a level curve.
- The random term has no range or distribution.
- Existing packet observations lack controlled character state.
- No source establishes a clamp, rounding order, numeric class id, or exact
  trait identity for the calculation.

## Further research

Use patch-scoped observations that bind command 27100 to known level, INT,
trait, gear, and buff state. Preserve the player calculation as a source claim
until controlled trials reproduce or refute each term.
