# FFXIV 1.x Lodestone - A Beginner's Guide to Eorzea

## Study contents

Clean Markdown transcription of the **12 "A Beginner's Guide to Eorzea" columns**
from the 1.x Lodestone - dev-written new-player gameplay tips and Q&A, dated
2010-10-25 to 2011-02-14. ~12,000 words, 215 images, one `.md` per column. The
informal companion to the official game manual: it walks a new player through
getting around, maps/enemies/class rank, the interaction menu, guildleves,
battle basics and passive/active mode, setting actions to the action bar,
trading, Disciple of the Hand stats, and more (see `derived/index.md` for the
per-column topics).

Provides first-party reference material for downstream consumer onboarding.

**Evidence tier.** First-party SE tips of design **intent** - stronger than
community wiki, but observed packet/video still outranks it for runtime values.
This content overlaps the manual's how-to-play material.
