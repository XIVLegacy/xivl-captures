# Music ID, title and usage crosswalk

The retained Music revision 1196 table supplied candidates for IDs 1 through
109. The [crosswalk](derived/music-crosswalk.csv) keeps each source name and
usage description separate from title confidence, version scope and selected
retail numeric evidence. A title or regional usage in this table does not
establish a shipped audio resource or a historical per-zone selection rule.

The [evidence map](derived/evidence-map.md) owns the field definitions,
retail intersections, ambiguities and reproduction procedure. The
[source manifest](../../sources/classic-music-reference/manifest.yaml) owns
the inspected HTML's revision, digest and provenance. Its evidence class is
`web-tables`; the original HTML remains local-only.
